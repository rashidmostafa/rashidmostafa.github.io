Privacy Policy

Threat Brief uploader · Last updated 20 October 2026

1. Who we are

The Threat Brief uploader ("the tool") is a private, single-user tool operated by the owner of the Threat Brief YouTube channel (contact: rashidmostafa002@gmail.com). It is used only by the channel owner to upload the channel's own videos. It has no other users and is not available to the public.

2. Use of YouTube API Services

The tool uses the YouTube API Services to upload videos and set video thumbnails on the owner's own YouTube channel. By using the tool, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

3. What information the tool accesses

  • Permission used: https://www.googleapis.com/auth/youtube.upload (upload videos and thumbnails) only.
  • The tool does not read, collect or display YouTube data such as comments, analytics, subscriber lists, watch history or other users' information.
  • The only data sent to YouTube is the channel's own video files, thumbnails, titles, descriptions and tags.

4. How information is stored

The only credential kept is an OAuth refresh token for the owner's channel, stored as an encrypted secret in the owner's private GitHub account so scheduled uploads can run. No YouTube API data is stored, and no personal data of any other person is collected.

5. Sharing

The tool does not share, sell or transfer any data to third parties. Video content is sent only to YouTube.

6. Cookies and tracking

The tool sets no cookies and uses no tracking or analytics. This website sets no cookies.

7. Revoking access and deleting data

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions (choose "Threat Brief" and remove access).
  • When access is revoked, or on request by email, the stored refresh token is deleted within 7 days. Because the tool stores no other YouTube API data, nothing else needs to be deleted.
  • Requests: rashidmostafa002@gmail.com.

8. Changes

If this policy changes, the updated version will be posted on this page with a new date.
